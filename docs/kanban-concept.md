# カンバン構想（未実装）

現時点では実装しない。方向性の記録用。

## 全体像

カンバンは **プロジェクト配下** で使う。

```
プロジェクト（名前・アイコン画像・参加者）
└── カンバン（ボード）
    └── リスト（列）
        └── カード（タスク）
```

## プロジェクト

- プロジェクト名を設定する
- アイコン画像を登録できる（アップロード）
- 参加者（メンバー）を設定する
- **参加していない人は見られない**（一覧にも詳細にも出さない）
- システム管理者はすべての操作ができる（`Gate::before` で許可済み）

## リアルタイム更新

カンバンの操作（カードの移動・追加・編集など）は、開いている全員の画面に
リアルタイムで反映されるようにしたい。

- 候補: Laravel Reverb（WebSocket）＋ Laravel Echo
- プロジェクト（またはボード）単位のプライベートチャンネルにし、
  参加者だけが購読できるようにする

## 想定するテーブル

| テーブル | 用途 |
| --- | --- |
| `projects` | プロジェクト（名前、アイコン画像パス など） |
| `project_user` | プロジェクトと参加者の中間テーブル |
| `boards` | プロジェクト配下のカンバン |
| `board_columns` | カンバンの列（ToDo / 進行中 / 完了 など） |
| `cards` | カード（タスク）。並び順を持つ |

※ シーダーはテーブルごとにファイルを分ける（`database/seeders/`）。
